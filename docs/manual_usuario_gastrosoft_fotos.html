1. Introducción y navegación general

GastroSoft es un sistema web para administrar la operación diaria de un restaurante. Permite controlar mesas, comandas, productos, reservaciones, pagos, inventario, empleados, proveedores, caja y reportes desde una sola plataforma.

Objetivo del sistema

Ayudar al personal a trabajar más rápido y con menos errores, manteniendo toda la información del restaurante organizada.

Usuarios del sistema

Meseros, cajeros, gerentes y administradores. Cada usuario puede ver módulos según sus permisos.

Barra superior

Desde la barra naranja se cambia de módulo, se revisa el usuario activo y se cierra sesión.

Botones y colores

Verde confirma, azul edita, rojo cancela o elimina, naranja destaca acciones principales.

Recomendación: un usuario nuevo debe iniciar revisando Dashboard, después Mesas y finalmente Comandas, Pagos o Reservaciones según su tarea.

14. Promociones

El módulo Promociones permite manejar descuentos, combos y ofertas. En el ZIP recibido no venía una captura separada de Promociones, por eso esta página explica el uso funcional y se apoya en la operación de comandas y menú.

¿Qué hace?

Permite consultar o administrar promociones que pueden aplicarse a productos o combos.

¿Dónde se usan?

Al crear una comanda, las promociones disponibles aparecen para agregarlas como combo o descuento.

Ejemplos

Hora feliz, 2x1 en pizzas, menú del día o menú infantil.

Precaución

Revise que la promoción esté activa antes de aplicarla al cliente.

  1. 1
    Entre al módulo Promociones desde la barra superior.
  2. 2
    Revise nombre, descripción y estado.
  3. 3
    Al crear una comanda, seleccione la promoción correspondiente si aplica.
  4. 4
    Confirme el total antes de guardar o cobrar.
Si me pasas una captura de Promociones, puedo reemplazar esta página por una guía visual con puntos sobre la foto real.

16. Preguntas frecuentes

No puedo iniciar sesión

Revise usuario, contraseña y que su cuenta esté activa.

No aparece un módulo

Puede ser por permisos. Consulte al administrador.

No encuentro una comanda

Use el buscador por mesa o cliente y revise los filtros.

No hay mesas disponibles

La mesa puede estar ocupada o reservada.

Inventario agotado

Registre una entrada si llegó mercancía o avise al encargado.

Error en pago

Revise la comanda antes de confirmar. Si ya se confirmó, consulte al administrador.

17. Glosario

Comanda

Orden de productos asignada a una mesa o cliente.

Cuenta separada

División de una comanda por persona para cobrar individualmente.

Reservación

Mesa apartada para un cliente, fecha y hora específica.

Stock

Cantidad disponible de un ingrediente.

Entrada

Movimiento que aumenta inventario.

Salida

Movimiento que descuenta inventario.

Caja

Control de efectivo y movimientos del turno.

Rol

Permiso asignado al usuario para acceder a módulos.
